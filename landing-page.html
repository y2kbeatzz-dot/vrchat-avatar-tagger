A free desktop app that bulk-applies VRChat's Content Warning tags across your whole avatar library — instead of clicking through each one on the website.

Get it on GitHub See how it works
The problem

Content-warning tagging, one avatar at a time, does not scale.

If you've got a handful of avatars, the website is fine. If you've got dozens, it's a lot of identical clicking for identical tags.

What it does

Everything the website makes you do by hand.

⚡

Bulk add or remove

Select as many avatars as you want and add or remove any of the five content-warning tags across all of them in one run.

🏷️

Custom tags

Not limited to the built-in five — type any tag you want applied or removed, on one avatar or a hundred.

👁️

Dry run preview

See exactly what would change before anything actually does. Nothing touches your account until you turn dry run off.

✏️

Per-avatar editor

Double-click any single avatar to see its full tag list and fix anything directly — add, remove, or correct one at a time.

💾

Resume automatically

Progress saves as it runs. Stop halfway through a big batch, close the app, come back later — it picks up where it left off.

🌙

Dark mode

Because you're tagging avatars at 2am and the default white background was never going to happen.

How it works

Three steps. No repeated clicking.

01

Log in

Sign in with your VRChat account. Email and authenticator 2FA are both handled with a simple popup.

02

Select avatars & tags

Search your library, pick which avatars to affect, choose which tags to add or remove — presets or custom.

03

Apply

Preview with dry run, then apply for real. Watch a live log while it runs, with a stop button if you change your mind.
